# BrightPath

BrightPath Youth, Inc. is an Ohio nonprofit focused on structured leadership and financial intelligence for young learners.

## Diversity and Inclusion

BrightPath welcomes students and families from diverse backgrounds, identities, abilities, and learning journeys. The program is designed to support respectful participation, accessible communication, and a learning culture where every student can build confidence, clarity, and ownership.
